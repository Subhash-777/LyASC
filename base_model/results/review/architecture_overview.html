🧮 Layer-Normalized Residual Block Architecture & PyTorch Implementation
📐 Operational Mathematical Flow
  1. Parallel Skip Sum: S(x) = ∑k=1..K xk
  2. Scaling Factor: λ = 1 / √K (for rSkip) or learnable w (for wSkip)
  3. Layer Normalization: Normalizes spatial coordinate channels independently:
    μh,w = (1/C) ∑c xc,h,w
  4. Residual Branch: F(x, W) = Conv3x3(ReLU(BN(Conv3x3(ReLU(BN(x))))))
  5. Combination: y = LayerNorm2d( λ · S(x) ) + F(x, W)
💻 PyTorch LayerNorm2d Implementation (Channel-Wise)
class LayerNorm2d(nn.Module): """Channel-wise LayerNorm per (H, W) spatial position.""" def __init__(self, num_channels: int, eps=1e-5): super().__init__() self.weight = nn.Parameter(torch.ones(num_channels)) self.bias = nn.Parameter(torch.zeros(num_channels)) self.eps = eps def forward(self, x: torch.Tensor) -> torch.Tensor: # x: [B, C, H, W] u = x.mean(1, keepdim=True) s = (x - u).pow(2).mean(1, keepdim=True) x = (x - u) / torch.sqrt(s + self.eps) x = self.weight[:, None, None] * x + self.bias[:, None, None] return x
