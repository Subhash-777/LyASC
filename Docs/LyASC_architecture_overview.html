🧬 LyASC Residual Block Formulation & Tensor Flow
LyASC Adaptive Gate & Combination Equation
αl = σ( βl · ( λl − λ0 ) )
yl = αl · xl + ( 1 − αl ) · Fl(xl)
Where λl is the estimated local finite-time Lyapunov exponent proxy, λ0 is the stability threshold, and βl is a learnable sensitivity scalar (initialized to 0 so αl = 0.5).

🧮 Stability Estimator Algorithm & PyTorch Implementation
📋 Power Iteration Algorithm Steps
  1. Sample random unit probe vector v in block input space.
  2. Compute Jacobian-vector product u = J_l · v via PyTorch autograd forward-mode / reverse-mode.
  3. Normalize probe: v ← u / ||u||
  4. Repeat for k = 2 iterations.
  5. Estimate proxy: λ_l ≈ log(||u||)
  6. Smooth over training steps via Exponential Moving Average (EMA decay = 0.9).
  7. Recompute only every N = 10 steps to amortize overhead (~2%).
💻 LyASCSkip PyTorch Module
class LyASCSkip(nn.Module): """y = alpha * x + (1 - alpha) * F_x""" def __init__(self, channels: int, lambda0: float = 0.0, estimator=None): super().__init__() self.beta_l = nn.Parameter(torch.zeros(1)) # init 0 -> alpha=0.5 self.lambda0 = lambda0 self.estimator = estimator def forward(self, x: torch.Tensor, F_x: torch.Tensor) -> torch.Tensor: lam = self.estimator.current_value() # cheap cached read alpha = torch.sigmoid(self.beta_l * (lam - self.lambda0)) return alpha * x + (1 - alpha) * F_x
